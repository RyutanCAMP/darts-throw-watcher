# 正式版のリリース手順

## しくみ
| 種類 | 作られるとき | 置き場所 | アプリ名 / ID |
|---|---|---|---|
| **正式版** | `v1.0.0` のようなタグを push | Releases の **Latest**（常に最新の正式版） | 投擲ウォッチャー / `jp.ryutancamp.throwwatcher` |
| テスト版 | ブランチに push | `test-latest`（main）・`test-pr`（その他） | 投擲ウォッチャー(テスト) / `jp.ryutancamp.throwwatcher.test` |

- 正式版のダウンロードURL（変わらない）：
  https://github.com/RyutanCAMP/darts-throw-watcher/releases/latest/download/throw-watcher.apk
- 正式版は毎回同じ鍵で署名 → **アンインストールせずに上書き更新できる**
- テスト版は別アプリ扱いなので、正式版と並べて入れられる

## 最初に1回だけ：署名鍵をシークレットに登録（唐川さん）
GitHub → darts-throw-watcher → Settings → Secrets and variables → Actions →「New repository secret」で4つ登録：

| Name | 中身 |
|---|---|
| `RELEASE_KEYSTORE_BASE64` | `RELEASE_KEYSTORE_BASE64.txt` の中身（長い1行） |
| `RELEASE_KEYSTORE_PASSWORD` | `RELEASE_KEYSTORE_PASSWORD.txt` の中身 |
| `RELEASE_KEY_ALIAS` | `throwwatcher` |
| `RELEASE_KEY_PASSWORD` | `RELEASE_KEY_PASSWORD.txt` の中身 |

**鍵ファイル（release.jks とパスワード）は必ず安全な場所にバックアップ**（パスワード管理アプリや Google ドライブの非公開フォルダなど）。
なくすと、同じアプリとして更新できなくなる（入れ直しが必要になる）。リポジトリには絶対に入れない。

## リリースするとき（毎回）
1. `app/build.gradle.kts` の `versionCode` を1つ以上増やし、`versionName` を上げる（例 1.0.1）
2. main に取り込む
3. タグを push：`git tag v1.0.1 && git push origin v1.0.1`
4. Actions の「Release (正式版)」が緑になれば、Releases の Latest に APK が置かれる

## 旧版に戻すとき
- Releases から前のバージョンの `throw-watcher.apk` を入れる
- バージョンを下げる場合は Android が上書きを拒否するので、アンインストールしてから入れる（ユーザー補助を ON にし直す）
