# PC連携（Firestore 経由）の実装記録（2026-11-26）

- 指示者：唐川 ／ 担当：クロ（Claude）
- 対象：darts-throw-watcher v0.2.0-test ＋ darts-training-lab v0.5.42

## しくみ
```
200S ─(Bluetoothキー)→ Android ─ ユーザー補助で見るだけ → 公式アプリへそのまま
                          └→ Sender（別スレッド）→ Firestore links/{コード}/throws/{id}
                                                          ↓ リアルタイム
                                    PC darts-training-lab（PLAY に 200S と同じ処理で反映）
```
- ログインなし。PC で発行した8文字のコード（0/1/I/O/L を除く）が合言葉
- スマホは Firestore の REST API を直接使う（ライブラリなし）。docId をスマホで決めるので再送しても二重にならない
- 送る中身：`seg`（T20・S20I・IB・START・CHANGE など）、`t`（時刻 ms）、`n`（連番）だけ

## ルール（firestore.rules の links ブロック）
- コードを知っていれば読める・書ける。コードの一覧は取れない
- links は作成のみ（上書き・削除不可）、throws は追記のみ。形と区画名をルールでチェック

## PC側のふるまい
- PLAY の「PHONE」チップ → 連携コード発行、受信ログ、「PLAYに反映（COUNT-UP）」ON/OFF
- PC のページを閉じていた間に届いた投擲は記録のみ（PLAYには入れない）
- スマホ側が正：ラウンド待ち中に次の1投が来たら待ちを終えて反映、24投後に次の1投が来たら結果を確定して次ゲームへ
- COUNT-UP 以外を投げるときは「PLAYに反映」を OFF にする（受信記録だけ残る）

## 実機での手順
1. 唐川さん：Firebase コンソール → Firestore → ルール に、darts-training-lab の `firestore.rules` を丸ごと貼って「公開」
2. PC：darts-training-lab を開く → PLAY →「PHONE」→「連携コードを発行」
3. スマホ：投擲ウォッチャー v0.2.0 を入れ直す → コードを入力して「連携」→「● 連携中」になればOK
4. 公式アプリで COUNT-UP → PC の PLAY に1投ずつ入るか確認
